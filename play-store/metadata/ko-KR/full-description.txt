타이디 런처는 기본 홈 앱으로 설정하는 순간 안드로이드 홈화면을 자동으로 정리해주는 런처입니다.

앱을 하나씩 끌어다 놓을 필요가 없습니다.
폴더를 손으로 다시 만들 필요도 없습니다.
계정도 필요 없습니다.
모든 처리는 기기 안에서 끝납니다.

타이디 런처는 휴대폰에 이미 설치된 앱을 읽어와 자동으로 새 홈화면 레이아웃을 만듭니다.

정리 방식은 두 가지입니다.

- 기능별 정리: 소셜, 업무, 금융, 쇼핑, 미디어, 이동, 유틸리티, 게임, 건강, 도구 폴더로 자동 분류
- 색상별 정리: 아이콘 색감 기준으로 폴더를 만들어 더 정돈된 느낌 제공

페이지 구성도 선택할 수 있습니다.

- 1페이지 모드: 최대한 압축해서 빠르게 접근
- 2페이지 모드: 핵심 앱을 더 넉넉하게 배치

타이디 런처의 핵심 장점:

- 어질러진 홈화면을 자동 정리
- 새 앱을 설치하거나 삭제해도 자동으로 다시 정리
- 앱서랍에서 기능별/색상별 두 보기 제공
- 홈화면에서 바로 검색 가능
- 영어/한국어 지원

개인정보 보호 중심:

- 로그인 없음
- 분석 수집 없음
- 서버 전송 없음
- 클라우드 동기화 없음
- 설치 앱 정보와 분류 결과는 기기 내부에만 저장

프리미엄:

기본 자동정리 기능은 무료로 제공됩니다. 프리미엄에서는 추가 레이아웃 프리셋, 테마, 저장된 정리 스냅샷, 더 많은 커스터마이징 기능을 사용할 수 있습니다.

타이디 런처는 삼성 One UI나 Pixel Launcher를 뒤에서 조작하지 않습니다. 사용자가 기본 홈 앱으로 설정한 이후 타이디 런처 안에서 정리 기능이 동작합니다.
