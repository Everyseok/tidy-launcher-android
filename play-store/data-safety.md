# Google Play Data Safety Draft

## Collected data

- No data collected for analytics
- No data collected for advertising
- No personal info collected for account systems

## Processed on device only

- Installed app list
- App labels and package names
- App icons used for local color grouping
- Launcher preferences and layout choices

## Shared data

- No data shared with third parties

## Security

- Data is processed on-device only
- No account backend is used in the current MVP
